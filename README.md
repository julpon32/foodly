# Foodly

Личный дневник разнообразия питания: запись блюд, проверка ингредиентов, история по дням и количество уникальных продуктов.

Записи сохраняются только в localStorage текущего браузера. Серверной синхронизации пока нет. Это личный прототип, без медицинских оценок.

## Разработка

- `npm ci` — установить зависимости (Node.js 24).
- `npm run dev` — локальный предпросмотр.
- `npm run build` — сборка.
- `npm run lint` — проверка кода.

## Публикация

GitHub Actions публикует ветку `main` на https://julpon32.github.io/foodly/.
При сборке для Pages задаётся `GITHUB_PAGES=true`, чтобы использовать путь `/foodly/`.
Локальные изменения нужно отправить в GitHub; только после этого запускается публикация.

## Локальное обновление интерфейса

- Распознавание ингредиентов: локальный русский словарь и несколько шаблонов блюд в `src/food.ts`. Предполагаемый состав всегда требует проверки. Это не AI-сервис: неизвестные блюда вводятся вручную, сложные отрицания и произвольные рецепты могут распознаваться неполно.
- Главная показывает уникальные продукты и четыре пересекающиеся группы. Клетчатка обозначает источники, а не граммы. Diversity Score не рассчитывается.
- `npm test` проверяет распознавание, исключения и подсчёт групп.
- Проверка сборки для Pages: `GITHUB_PAGES=true npm run build`, затем `GITHUB_PAGES=true npm run preview`. Открыть локальный адрес с `/foodly/`.
- Иллюстрации в `public/food` подготовлены по согласованному листу графики. Они не персональные рекомендации.
