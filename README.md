# Foodly

Личный дневник разнообразия питания: запись блюд, проверка ингредиентов, история по дням и количество уникальных продуктов.

Записи сохраняются только в localStorage текущего браузера. Серверной синхронизации пока нет. Это личный прототип, без медицинских оценок.

## Разработка

- `npm ci` — установить зависимости (Node.js 24).
- `npm run dev` — локальный предпросмотр.
- `npm run build` — сборка.
- `npm run lint` — проверка кода.

## Публикация

GitHub Actions публикует ветку `main` на https://julpon32.github.io/foodly/.
При сборке для Pages задаётся `GITHUB_PAGES=true`, чтобы использовать путь `/foodly/`.
Локальные изменения нужно отправить в GitHub; только после этого запускается публикация.
